# بالعربي (In Arabic)

ترجمة عربية فورية لترجمات ألعاب البلايستيشن 5 على الشاشة.

- **الجوال (أندرويد):** يشغّل البلايستيشن عن بعد (Remote Play)، يقرأ الترجمة الإنجليزية من الصورة، يترجمها بترجمة جوجل (Google Translate، بدون مفاتيح)، ويرسلها للشاشة.
- **شاشة أندرويد:** نافذة شفافة فوق مدخل الـHDMI تعرض الترجمة العربية فوق الإنجليزية.
- **شاشة LG:** تطبيق يعرض مدخل الـHDMI داخله والترجمة فوقه.

الملفات الجاهزة في صفحة [الإصدارات](../../releases/latest).

## الترخيص
تطبيق الجوال مبني على [chiaki-ng](https://github.com/streetpea/chiaki-ng) (AGPL-3.0)، ولذلك المشروع كله مفتوح المصدر بنفس الترخيص (انظر COPYING و README-chiaki-ng.md).
